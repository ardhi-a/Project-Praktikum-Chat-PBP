Chat App - Pemrograman Berbasis Platform

Deskripsi
Chat App merupakan aplikasi pesan sederhana berbasis web yang dikembangkan untuk memenuhi tugas mata kuliah Pemrograman Berbasis Platform (PBP).

Aplikasi ini dirancang agar pengguna dapat melakukan komunikasi melalui pesan secara online.

Teknologi yang Digunakan:
-HTML
-CSS
-JavaScript Native
-PHP Native
-MariaDB
-JSON API
